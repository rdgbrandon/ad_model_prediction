# Feedback-driven rerun

Start with [the measured supplement](rerun/sases_theory_rerun.pdf),
[results](rerun/results.md), and [paper revisions](PAPER_REVISIONS.md).
The original PDF atlas and historical JSON files are retained as historical
outputs. Their conformal-guarantee wording is superseded by these qualifications.

## Run from the repository root (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r sases_eval/requirements-rerun.txt
.\.venv\Scripts\python.exe sases_eval/build_dataset.py
.\.venv\Scripts\python.exe -m unittest discover -s sases_eval -p test_theory_audit.py -v
.\.venv\Scripts\python.exe sases_eval/theory_audit.py
.\.venv\Scripts\python.exe sases_eval/report_theory_audit.py
```

Python 3.8.10 was used. The direct dependency versions are pinned;
`rerun/environment-lock.txt` records the complete installed environment.
The archived `spec_before_rerun.npz` is supplied for the rebuild comparison;
do not replace it with new arrays when reproducing the comparison.
The builder now uses paths relative to its source file and writes to
`sases_eval/spec.npz`, replacing an obsolete hard-coded temporary directory.
The evaluation data loader also works independently of the working directory.

## What is new

- Spectrum reconstruction from HDF5, with an exact comparison to archived arrays.
- Fixed comparison of a calibration-only KZ slope gap, with/without a measured
  boundary residual, against the fitted-rate and historical 2x rules.
- Both original LOTO b (heuristic) and already-labelled anchor error (exact for
  the empirical target) are exposed explicitly.
- Seven model/seed fits, two canonical ceilings and the 22-split x 12-anchor sweep.
- Trial-level counts and nominal one-sided 95% Clopper-Pearson references.
- Raw rows, frozen calibration fits, hashes, code, versions, figures and PDF.
- Five tests, including perturbing test labels to verify fit independence.

## Interpretation

Read `RERUN_PROTOCOL.md` for the fixed assumptions. The derivative bound underlying
the theory candidate is an assumption to audit, not a consequence of weak
turbulence for this apparatus. Drive power is not a measured energy flux. No
multiplier was tuned to this rerun's test residuals. However, these test data
were already inspected during the original study, so this remains retrospective.

The canonical anchor is the first maximum-power training trial (`_42_1`, 54 mW),
preserving the existing tie rule; the anchor sweep includes both 54 mW repeats.
All above-break trials used to fit a law are disjoint from its test trials.
Across the 22 overlapping splits a trial can be calibration in one configuration
and test in another. These are sensitivity configurations, not independent test
sets or a basis for selecting a rule with a fresh-test claim.

The slope-only rate can miss a nonzero residual at the calibration boundary.
The boundary candidate retains that value and adds a derivative-gap term.
At the 146 mW ceiling the Setup C fitted rule abstains: three law-calibration
trials cannot supply a held-out fourth trial after fitting a three-trial sub-law.
This is deliberately distinct from the older beta_v2 two-trial-sub-law estimator.

Raw CSV has both seeds and repeated configurations; never use its row count as
the binomial n. Sweep summaries define success as a trial passing *all* its
configurations; the pooled fraction is only descriptive. CP bounds are nominal
IID-binomial references, because the apparatus/power sampling is not IID by design.
One-sided 95% lower bounds: 3/3 = 0.368 and 4/4 = 0.473. At least 29 independent
successes without failure are needed for that bound to exceed 0.90.

Known target restriction: labels are trial means of log spectra. A measured
anchor error is exact against those labels, not an unknown noise-free target.
The original LOTO quantile does not establish a conformal guarantee at a chosen
boundary anchor for the final refitted model.

Historical synthetic/deep-ensemble results and the older PDF atlas are not
regenerated by this runner. The new PDF states its evaluated scope explicitly.
