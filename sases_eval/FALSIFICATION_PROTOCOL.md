# Adversarial audit (exploratory, existing corpus already viewed)

Do not tune the certificate or rewrite old outputs. Test the current functions.
Separate failures of an unconditional interpretation from counterexamples to
the conditional distance-to-set theorem. No synthetic case is a physical trial.

1. Construct smooth calibration-indistinguishable targets, a biased anchor,
   an exact-law target, and disjoint calibration balls. Record scores and truth.
2. On the stored 78 ceiling rows, shrink radius to zero as a deliberately false
   premise and count whether ordinary surrogate bound checks notice. This is
   a negative control, not a proposed improved method.
3. On the 49 canonical ctr12 rows (seven fits, two splits, four unique physical
   test trials), compare SASES to classical componentwise Lipschitz envelopes.
   Fixed trend alternatives: zero and 0.5. Estimate each residual coordinate's
   Lipschitz constant by the maximum LAWCAL secant, then intersect all transported
   coordinate intervals. This empirical constant is NOT a global certificate.
   No test label is used to set slopes or intervals. Empty boxes abstain.
   Also test the exact ideal-law point region, explicitly requiring stronger
   assumptions than the historical empirical ball. Score premise and bound
   validity separately. Report all failures, no tuned inflation.
4. Reproduce all reported counts with assertions and retain source hashes.
5. After the preceding fixed audit, compare the existing consensus to the
   standard nonnegative Lagrange dual of projection onto its SAME ball
   intersection. Do not change any centre or radius. Recompute the dual lower
   bound from feasible nonnegative multipliers; a primal feasible point gives
   a numerical optimality-gap check. This isolates geometry from physical claims.

Mechanism baseline: envelope construction is the scalar set-membership method
of Milanese and Novara (2004), applied componentwise to detrended outputs.
This is not claimed to be their exact implementation or a globally valid
estimator of the Lipschitz constants. Source:
